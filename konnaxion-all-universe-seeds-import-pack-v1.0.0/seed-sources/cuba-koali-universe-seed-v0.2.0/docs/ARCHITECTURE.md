# Architecture de simulation

```text
Universe cuba-2026
  └─ World cuba-koali-offline
      └─ WorldRelease
          ├─ Konnaxion / Ethikos : débats, sources, consultations, DecisionRecords
          ├─ EkoH : expertise synthétique des personas
          ├─ Smart Vote : lecture dérivée seulement, jamais seedée comme vérité
          ├─ Orgo : exécution après décision gouvernée
          └─ Koali Spaces : composition/presentation, jamais autorité
```

## Offline

Le World initialise une contrainte offline-first cohérente avec Koali : état local, synchronisation ultérieure, provenance et continuité. Les éléments microSD / USB / nœud école / transport local sont des données narratives. Aucune procédure de dissimulation, d'accès non autorisé ou d'évasion n'est fournie.

## Politique de persona

Les noms de comptes sont des pseudonymes transparents. Les acteurs sont synthétiques; ils ne représentent ni les acteurs de la série, ni des personnages historiques, ni des responsables cubains réels.
