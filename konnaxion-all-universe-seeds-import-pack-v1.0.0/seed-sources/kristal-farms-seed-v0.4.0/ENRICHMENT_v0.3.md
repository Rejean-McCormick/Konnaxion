# Kristal Farms — enrichissement v0.3

## Objet

Le v0.3 conserve l’architecture v0.2 et enrichit chaque World avec des faits externes documentés, transformés en **déclencheurs de débat** Ethikos.

## Principes

- 3 déclencheurs spécifiques par World;
- sources privilégiées: gouvernement, institution ou organisation concernée;
- faits formulés par `kristal_moderator`, sans stance attribuée à une personne réelle;
- chaque fait est marqué `simulation_trigger_not_commercial_signal`;
- ajout transversal des *Responsible Data Centre Development Principles* annoncés par le Canada le 3 septembre 2026;
- aucune conclusion de sélection de site, capacité, autorisation communautaire ou intérêt commercial.

## Corrections de données

- `Hydro-Québec` possède maintenant la clé globale stable `institution:qc:hydro-quebec` dans tous les Worlds.
- AWTI: la fausse persona institutionnelle du v0.2 est remplacée par la présidente réelle Mirjam van Praag comme référence `source_only`.
- CSTI Japon: suppression de la fausse “personne” créée à partir du nom du conseil; CSTI reste une institution simulable sans titulaire fictif.
