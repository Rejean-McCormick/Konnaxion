# World Persona Seed Contract

Contract: `kx-world-personas/v1`

This is the Konnaxion host projection contract used inside `ethikos-demo-scenario/v3` metadata. It does **not** replace the ethiKos actor schema, create a second identity system, or become an epistemic authority.

```json
{
  "metadata": {
    "persona_contract": "kx-world-personas/v1",
    "persona_projection": {"mode": "standard"},
    "actor_profiles": {
      "actor_key": {
        "persona_type": "organization",
        "account_type": "service",
        "simulation_eligible": true,
        "ethikos_elite": true,
        "entity_type": "institution",
        "representation_type": "institutional_role"
      }
    }
  }
}
```

## Canonical Konnaxion primitives

- `simulation_eligible` controls whether a synthetic persona may be made active; for a `simulated_person`, eligible projection normally yields `User.is_klone=true`.
- `ethikos_elite` maps directly to the existing `User.is_ethikos_elite` flag. It is **not** the complete participation rule: Konnaxion also allows klone personas and staff through `User.can_participate_in_ethikos`.
- `ethikos_write` is accepted only as a backward-compatible v1 alias for `ethikos_elite`; new seeds should not emit it.

## Projection modes

### `standard`

Default. Domain metadata may be carried in `actor_profiles` and is preserved on the release bridge. It remains operational seed metadata; EkoH is never inferred from it.

### `identity_binding_only`

Use when epistemic authority belongs to an external knowledge system such as Kristal. The host adapter enforces that persona profiles contain only identity/representation/binding data and no embedded role, expertise, credential, provenance, claim, certainty or authority-recognition truth fields.

A strict profile must include:

```json
{
  "persona_contract": "kx-world-personas/v1",
  "persona_projection": {
    "mode": "identity_binding_only",
    "epistemic_authority": "external"
  },
  "actor_profiles": {
    "actor_key": {
      "persona_type": "simulated_person",
      "account_type": "human",
      "simulation_eligible": true,
      "ethikos_elite": false,
      "representation_type": "role_simulation",
      "external_referents": {
        "kristal": "example:person:alice"
      },
      "knowledge_projection": {
        "authority": "kristal_v5_runtime_pack",
        "binding": "referent_ref",
        "runtime_pack_required_for_epistemic_claims": true
      }
    }
  }
}
```

In this mode `WorldPersona.metadata_json` is an operational identity/binding projection, never the source of truth for role, expertise, credentials, evidence, certainty or recognition.

## Invariants

- `actors[].key` is the stable logical source identity.
- `WorldPersona(world, source_key)` is the stable World projection.
- `WorldPersonaBridge(persona, release)` owns the release-local auth bridge User.
- Bridge usernames are generated by Konnaxion_Worlds and are never canonical actor IDs.
- Bridge Users always have unusable passwords; they are not authentication principals.
- `persona_type` is stable across releases and cannot silently drift.
- `simulation_eligible=false` disables klone projection and seed-derived elite permission.
- EkoH remains World-local and is not derived from Persona metadata.
- External knowledge/runtime activation remains owned by its declared external authority; promoting a WorldRelease does not activate a Kristal Runtime Pack.
